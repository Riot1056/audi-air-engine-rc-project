# Audi S1-inspired inline-five concept model

Open `Audi_S1_Inline5_Concept.scad` in OpenSCAD and press F5 to preview. The file uses millimeters. Change `crank_angle` to rotate the simplified piston-and-crank arrangement. Change `show_part` to view one component group: `assembly`, `block`, `barrels`, `head`, `pistons`, `rods`, or `crankshaft`.

## Important limits

- This is a first visual concept, not a faithful scale replica of Audi's original engine.
- The crank throw phase values and rod geometry are placeholders for visualization; they are not engineering-validated.
- It is not a working compressed-air engine and is not pressure-rated.
- Do not print an air reservoir or pressurize the printed model. A future functional design must use a rated commercial reservoir and be reviewed by a qualified school instructor/mentor.
- The whole assembly is for inspection, not a one-piece print. Export and print individual parts only after clearances, joints, supports, and fit are redesigned for the exact school printer.

This model gives us a shared starting point for choosing scale and correcting the five-cylinder mechanism before making print-ready parts.


## Import into Tinkercad

1. Create or open a Tinkercad 3D design.
2. Choose **Import** and select `Audi_S1_Inline5_Concept_Tinkercad.stl`.
3. Keep the units set to **millimeters** and start at **100%** scale.
4. Tinkercad imports this STL as one mesh shape. It is useful for viewing and adding simple details, but the engine pieces are not separate editable Tinkercad primitives.

The assembled STL is for a digital concept view, not a one-piece print. It has intersecting and floating mechanical parts, and it is not pressure-rated.
